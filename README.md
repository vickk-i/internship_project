## 🧠 Project Overview

In modern healthcare systems, missed appointments disrupt operational flow, impact patient care, and increase financial waste. This project uses real-world medical appointment data to **identify patterns in no-show behavior** and provide actionable insights using an interactive Power BI dashboard.

By analyzing patient demographics, appointment details, and reminder effectiveness, the project enables clinics and hospitals to **optimize scheduling** and improve patient communication strategies.

---

## 🚀 Key Features

- 📊 **Interactive Dashboard** in Power BI
- 🔍 Insightful analysis on age, gender, SMS reminders, and weekdays
- 📅 Weekday trend analysis for missed appointments
- 📈 KPI cards for overall appointment stats and no-show rate
- 🧩 Clean UI with filters for neighborhood, gender, and age group
- 🎯 Supports strategic decision-making for appointment planning

## 💡 Key Insights

✅ Patients aged **0–35** had the highest no-show rates  
✅ **Females** missed more appointments than males  
✅ **Tuesdays** saw the most no-shows, **Saturdays** the least
